# GitEmUp

A fast, cross-platform GUI git client.

This repository hosts **installers and release notes only** — it is the public download point for GitEmUp. Source code is developed elsewhere; builds are produced locally and published here as [GitHub Releases](../../releases).

## Download

Grab the latest installer for your platform from the [Releases page](../../releases/latest):

| Platform | File |
|---|---|
| Windows | `GitEmUp_<version>_x64-setup.exe` (or `.msi`) |
| macOS | `GitEmUp_<version>_<arch>.dmg` |
| Linux | `GitEmUp_<version>_amd64.deb`, `.rpm`, or `.AppImage` |
